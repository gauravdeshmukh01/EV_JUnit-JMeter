HTML Report Generation using non-GUI mode in JMeter:

why we need non-GUI mode?

JMeter requires more resources in GUI mode.

GUI mode not suitable for heavy load testing, it will increase cost.

Integration with 3rd party software like JIRA/CI CLI mode is useful.

cmd : jmeter -? // for all - commands




step 1: open jmeter bin folder path in cmd


step 2: jmeter -n -t <location of jmeter file> -l <result file location>

-n : non gui
-t : test file
-l : log file

example:

                               // need to create csv file
